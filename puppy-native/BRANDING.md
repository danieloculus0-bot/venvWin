# venvWin Portable — native visual identity

Puppy remains the *engine*, not the public-facing product identity.

- Official name: **venvWin Portable**
- Visual direction: premium dark Linux Mint-adjacent desktop
- Base: charcoal `#101216`, text `#f4f2ee`, orange `#ff8a00`
- The first visible splash, the native boot menu, the wallpaper, GTK and JWM should use one coherent aesthetic.
- Existing wordmark is spelled **venvWin**; the accompanying label is **PORTABLE**.
- Artwork here is *typographic branding*, not a claim to replace a previously approved graphic logo. Do not invent a separate logo.
- Avoid Puppy labels in front-facing navigation, but preserve the underlying kernel, boot entries and recovery behavior.
- Wine capabilities and save/persistence must be verified, never faked in visuals or status.

The two SVG sources in `art/` are deterministic design sources. Before accepting any generated PNG in a boot image, compare the actual QEMU screen captures. **Never certify branding from file presence alone.**
